# The 26-discipline operating library

Version 2026.09.09-d26 · Prepared for Joseph · 9 September 2026.

This expansion treats website reliability, networking, engineering, accessibility, SEO, AI-search visibility, content, measurement and release assurance as distinct responsibilities within one coherent delivery process. The numbering preserves the user's exact 26 roles. These are **accountabilities and review lenses**, not an assertion that 26 separate employees or professional credentials exist.

Google describes AEO/GEO work for its own generative Search as part of core SEO, not a completely isolated replacement discipline. Other providers have their own crawler and reporting controls. This operating model separates specialist work where that prevents mistakes while preserving shared foundations. [Google's AI optimization guidance](https://developers.google.com/search/docs/fundamentals/ai-optimization-guide).

## Start here

1. Read the [operating model](00-OPERATING-MODEL.md) and [routing protocol](01-MASTER-ROUTER.md).
2. Fill the [site facts template](../../Templates/Disciplines/site-facts.template.json) with verified facts; unknowns remain null.
3. Select one lead and the necessary consulted roles. Read their charters and the linked current framework modules.
4. Diagnose read-only, record evidence and route ownership conflicts to R24. Use the [handoff contract](02-HANDOFF-CONTRACTS.md).
5. Apply the [acceptance and independence rules](03-ACCEPTANCE-AND-INDEPENDENCE.md) before any production or publication claim.
6. Build public expertise from the [publishing model](04-SEARCH-EXPERTISE-PUBLISHING.md), not from internal role titles.

The [integration guide](05-INTEGRATION-GUIDE.md) explains how to put these instructions in the actual project used by Codex. Downloading this package alone changes no external repository, site or account.
