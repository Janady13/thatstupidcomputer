# Homepage character and control deck — 2026-09-13

## Direction

Make the original computer an expressive host: a finite arrival routine, four scroll-triggered beats, and immediate reactions to the visitor's controls. Keep the illustrated workshop, actual links, existing story controls and real inquiry journey. No new renderer, dependencies, sound, forced scrolling or unsolicited rude gestures.

Palette: Workshop Paper #f4e5c4, Keycap Ivory #fff6df, Case Sand #dac69d, Charcoal Ink #29261d, Oxide #a44323 and Signal Green #36583c. Use the existing Arial/Helvetica interface and italic Georgia character voice, with small monospace key legends. Measure contrast after rendering.

Desktop composition: original room and CRT above a grounded, bevelled keyboard deck. A spoken caption sits above three substantial illustrated keys: New website / Website rescue / Get found. Utility controls use smaller physical keys; the demo is the return key. A four-mark scroll indicator shares the caption line. On sufficiently tall desktop screens, one short sticky scene lets the original rig act while the visitor scrolls; normal content follows immediately. No scroll interception. Narrow and short screens stay in normal document flow.

Interaction: wave and beckon on arrival; surprise, diagnosis and invitation on scroll; hand/face reactions when a key receives pointer or keyboard focus. Explicit stories and conversations outrank automatic cues. Automatic work stops while paused, reduced-motion, hidden or offscreen. A quiet rest follows the arrival routine; no endless attention loop. Use 180ms ease-in-out for tactile key transitions and finite, longer authored character gestures.

Pre-implementation critique: a larger generic card would hide the room again, and uncontrolled random motion would compete with the visitor. Keep the deck below the computer, preserve useful copy/hrefs, reserve the extra scroll distance for viewports that can show the entire stage, and test the priorities as actual browser behavior. The desktop and pocket rigs remain distinct and original.
